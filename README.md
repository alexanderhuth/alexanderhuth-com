# alexanderhuth.com

Professional/personal [website of Alexander Huth](https://alexanderhuth.com).

I use this little website as an online extension of myself and also as a playground to experiment with best practices, front-end configuration, and coding agents.

## Website at a glance
- Static site generated by Jekyll, built on statichost.eu (Ruby 3.4).
- Single-column layout with light and responsive CSS.
- Features content pages, blog posts, concert stats and stadium/grounds history, and a photo feed.
- Embraces the idea of slash pages (e.g., /now, /uses, /colophon).
- Background color changes randomly every page load/refresh.
