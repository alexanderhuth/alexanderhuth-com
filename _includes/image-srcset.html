{%- comment -%} srcset attribute value for a responsive image; the single home of the descriptor math used by photo-figure.html and grid-tile.html. Parameters: dir directory holding the size-step folders (e.g. "/images") fn file name incl. extension (e.g. "luna-sleeping.jpg") w, h dimensions of the full-size file at dir/fn steps comma-separated size steps to offer (default "480,720,960,1280") full also offer the full-size file dir/fn itself as the largest entry Variants bound the long edge, so a portrait file is narrower than its step name (a 720x960 photo yields 360px at the 480 step). Derive each descriptor from the aspect ratio so it states the file's real width. w/h are the full-size file's dimensions. Add just under half the divisor before dividing: Liquid truncates, and ImageMagick rounds an exact .5 down (644x960 at the 480 step is 322, not 323). {%- endcomment -%} {%- assign steps = include.steps | default: "480,720,960,1280" | split: "," -%} {%- if include.w > include.h -%}{%- assign long_edge = include.w -%}{%- else -%}{%- assign long_edge = include.h -%}{%- endif -%} {%- assign half = long_edge | divided_by: 2 | minus: 1 -%} {%- for s in steps -%} {%- unless forloop.first %}, {% endunless -%} {{ include.dir }}/{{ s }}/{{ include.fn }} {{ include.w | times: s | plus: half | divided_by: long_edge | at_most: include.w }}w {%- endfor -%} {%- if include.full %}, {{ include.dir }}/{{ include.fn }} {{ include.w }}w{% endif -%}
